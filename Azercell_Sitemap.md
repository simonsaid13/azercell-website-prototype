## Relationships

- Every page inherits the global header: **Personal** → `/en/`, **Business** → `/en/corporate.html`, **About us** → `/en/about-us.html`.
- Branch 1 (B2C) and Branch 2 (B2B) are structurally parallel: both have Tariffs → Internet → Roaming → Special/Value-added services, mirrored under different URL roots (`/personal/plans-and-services/…` vs. `/corporate/mobile-communications/…`).
- Branch 3 (Other/About Us) is linked from the global header on every page across Branches 1 and 2 — it is not nested under either.
- Branch 4 (External ecosystem) is not part of the azercell.com URL tree — each item is a separate domain/subdomain reached via a link from a specific page in Branches 1–3.
